# Published aggregate results

These files contain the final 261-domain historical/new comparison and separate historical selected-500 context. They contain no captured page text, per-domain differences, control values, prediction payloads, private labels or credentials.

- `summary.json` contains coverage, origin counts, limited-audit totals and cumulative costs.
- `contact-rates.csv` contains eight historical/new overall contact rows on 261 domains.
- `rates.csv` contains aggregate category/purpose/type rates with cohort and denominator columns.
- `requiredness.csv` describes declarations across exported controls, including partial sites.
- `figures/` contains the final PNG/PDF plots, aggregate heatmap cells and combined six-page PDF.
- `manifest.json` records source location and published file checksums.

Complete zero-form sites count as observed zeros; review does not establish absence. Contexts overlap, and gray heatmap cells are masked. Requiredness is declaration-only. The earlier small single-reviewer audit does not validate the final protocol. Fresh human labels remain unavailable.

Original captures, annotations and databases remain local. Inspecting these outputs does not rerun the pipeline.
